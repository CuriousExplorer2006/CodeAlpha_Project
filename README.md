# CodeAlpha_LanguageTranslationTool

A responsive web-based Language Translation Tool built as part of the CodeAlpha internship program.

## Features
- **Multi-language Translation:** Translate between 20 different languages using the MyMemory API.
- **Language Swapping:** Quick toggle button to swap source and target languages alongside input text.
- **Clipboard Support:** One-click copy for translated text.
- **Text-to-Speech (TTS):** Browser-native pronunciation (`SpeechSynthesis`) in the selected target language.
- **Keyboard Shortcut:** `Ctrl + Enter` to trigger quick translation.

## Tech Stack
- HTML5
- CSS3 (Responsive grid layout)
- Vanilla JavaScript (Fetch API & Web Speech API)

## Getting Started
Simply clone the repository and open `index.html` in any modern web browser:

```bash
# Clone repository
git clone https://github.com/<your-username>/CodeAlpha_LanguageTranslationTool.git

# Open index.html in your browser
```
